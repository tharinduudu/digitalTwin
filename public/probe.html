What these traces mean

The PCB, pad positions and net names come from the same KiCad board as the detector twin. A point on the same net has the same voltage in this lumped circuit model.

Signal chain

The analog impulse response is calculated offline with ngspice using the CH0 coupling capacitor, input and feedback resistors, and a reduced-order OPA846 model. The browser scales this response with the number of fired cells and assumed overvoltage. All four channels use the same nominal circuit. These traces do not predict measured channel-to-channel differences.

The assumed SiPM parameters are 140 pF terminal capacitance, 1.7 million electrons per avalanche at 3 V overvoltage, and a 0.8 ns rise / 30 ns fall current pulse. Pulse shape, optical yield and amplifier bandwidth have not been validated against this assembled detector. Fired cells are not incident photons or measured PDE.

Comparator and scope

The comparator uses the threshold DAC setting, assumed 8 mV hysteresis, nominal 2.5 ns propagation delay and finite edges. Output saturation is a simple rail clamp, not a model of recovery or slew-rate limits. The 20 MHz scope filter is first order. Probe attenuation is correctly compensated in the voltage display; it does not model input capacitance or cable reflections. AC coupling uses an assumed 10 Hz high-pass.

DC supplies and DAC outputs are ideal settled levels. There is no prediction of converter switching, supply ripple, DAC update glitches, I2C traffic, loaded FPGA firmware, LED timing, startup or faults. Unsupported nets show no trace. The 50 MHz clock is illustrative.

Bias values and ground

DAC voltage uses the stored calibration law: 0.0005 + 2.9968 x code / 1023 V. Its absolute accuracy is not established here. Effective SiPM bias = high side - low side. The breakdown voltage is an editable assumption, not a new measurement. Changing these fields never changes real hardware.

On this detector the SMA outer shield carries high voltage. It is not signal ground. Virtual probing cannot establish whether a real earth-referenced scope connection is safe. All displayed voltages are relative to PCB signal GND.
